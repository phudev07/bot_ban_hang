Import GPT vào 9Router

Công cụ giúp nhập dữ liệu GPT Free vào 9Router nhanh hơn. Chọn đúng bản theo hệ điều hành, sau đó chạy tool và làm theo hướng dẫn hiển thị.

⬇ Windows · import_to_9router.exe ⬇ Linux · import_to_9router.py
  1. Windows: tải file .exe và mở trực tiếp.
  2. Linux: mở Terminal tại thư mục tải về, chạy python3 import_to_9router.py.
  3. Chọn file dữ liệu đầy đủ .json mà bot gửi sau khi mua GPT Free.
  4. Kiểm tra lại thư mục/URL 9Router trước khi bấm Import.
Tool chỉ chạy trên máy của bạn và không cần gửi key/API của shop lên website. Không chia sẻ file đầy đủ vì file này chứa refresh token.
