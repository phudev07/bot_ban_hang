Import GPT vào 9Router

Chọn đúng gói ZIP theo hệ điều hành, giải nén rồi chạy công cụ bên trong.

⬇ Windows · import_to_9router.zip ⬇ Linux · import_to_9router.zip ⬇ macOS · import_to_9router.zip
  1. Windows: giải nén ZIP rồi mở import_to_9router.exe.
  2. Linux: giải nén ZIP rồi chạy python3 import_to_9router.py.
  3. macOS: giải nén ZIP, mở Terminal tại thư mục đó rồi chạy python3 import_to_9router_macos.py.
  4. Chọn file dữ liệu đầy đủ .json mà bot gửi sau khi mua GPT Free.
  5. Kiểm tra lại thư mục/URL 9Router trước khi bấm Import.
Bản macOS dùng Python 3 và tự dò thư mục ~/Library/Application Support/9Router. Nếu macOS chưa có Python 3, cài từ python.org hoặc Homebrew. Tool chỉ chạy trên máy của bạn và không cần gửi key/API của shop lên website. Không chia sẻ file đầy đủ vì file này chứa refresh token.
