BƯỚC 01

Kích hoạt mã CDK

Chỉ bắt đầu tính 24 giờ sau khi bạn kích hoạt CDK.

1

Copy CDK từ bot

Copy nguyên dòng mã được giao trong đơn hàng, không thêm dấu cách.

2

Mở trang kích hoạt

Truy cập api.maxdonchal.bond, dán CDK và xác nhận kích hoạt.

3

Lưu key sk-

Sau khi kích hoạt, copy key bắt đầu bằng sk-. Key này dùng cho cả hai cách bên dưới.

Quan trọng: không kích hoạt trước khi cần sử dụng, vì thời hạn 24 giờ được tính ngay từ lúc kích hoạt thành công.
CÁCH 01

Kết nối qua 9Router

Dùng cách này nếu máy đã cài và đang chạy 9Router.

OpenAI Codex CLI / App

Mở đúng trang CLI Tools của 9Router rồi điền endpoint, key, model và subagent model như hình.

Mở 9Router trên máy
  1. Select Endpoint → Custom URL...Nhập {{ gateway_url }}
  2. Khóa API → Custom...Dán key sk-... vừa nhận.
  3. ModelChọn ví dụ cx/gpt-5.6-sol.
  4. Subagent ModelChọn cùng model hoặc một model khác trong danh sách hỗ trợ.
  5. Bấm Áp dụngNếu Codex đang mở, hãy đóng hoàn toàn rồi mở lại để nhận cấu hình.

Chạy app portable

DỄ DÙNG NHẤT

VietShare Codex Portable

App dùng giao diện làm việc riêng nhưng tiếp tục đọc các cuộc trò chuyện Codex hiện có. Bạn chỉ cần nhập key, chọn model rồi làm việc.

  • ZIP chỉ chứa một file EXE portable, không có bộ cài.
  • Không ghi đè config.toml hoặc auth.json của Codex chính.
  • Không làm mất lịch sử hội thoại Codex hiện có.
  • Khi đóng app portable, bạn mở Codex chính và sử dụng như trước.
