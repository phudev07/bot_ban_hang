Phần 01

Kích hoạt key

Copy key bot đã giao, mở trang kích hoạt rồi dán key vào. Sau khi kích hoạt thành công, hệ thống trả về key API bắt đầu bằng sk-.

Mở trang kích hoạt key ↗
Key API nhận đượcsk-xxxxxxxxxxxxxxxx

Giữ kín key sk-. Thời hạn gói bắt đầu tính ngay khi kích hoạt thành công.
