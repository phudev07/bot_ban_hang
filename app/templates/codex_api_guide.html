Phần 06 · Bắt buộc

Cập nhật config.toml

Sau khi tạo provider và thêm key, mở file cấu hình Codex trên máy rồi thêm cấu hình dưới đây. Đặt model mặc định ở dòng đầu nếu muốn.

model = "cx/gpt-5.6-sol"
model_provider = "9router"

[model_providers.9router]
name = "9Router"
base_url = "http://localhost:20128/v1"
experimental_bearer_token = ""
wire_api = "responses"
requires_openai_auth = false
  • Windows: C:\Users\Tên máy của bạn\.codex\config.toml
  • Ubuntu: ~/.codex/config.toml
  • Prefix model phải là cx/, ví dụ cx/gpt-5.6-sol.
  • Đóng và mở lại Codex Desktop sau khi lưu file để nhận cấu hình mới.

Không xóa thư mục ~/.codex hoặc file lịch sử cũ. Chỉ thêm/cập nhật block provider trong config.toml.
