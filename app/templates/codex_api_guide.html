Codex · 9Router

Kết nối Codex Desktop qua 9Router

Thực hiện lần lượt 4 bước dưới đây. Cách này dùng provider đã có trong 9Router và không cần tạo thêm provider mới.

B1

Mở trang cấu hình Codex của 9Router

Trong 9Router, mở trang CLI Tools → Codex theo liên kết bên dưới.

{{ router_url }}
B2

Nhập thông tin như hình

Chọn Custom URL..., nhập gateway, chọn Custom... ở phần API key và điền model Codex. Có thể dùng gpt-5.6-sol cho cả Model và Subagent Model.

Custom URL
{{ gateway_url }}
B3

Ấn Lưu / Áp dụng

Kiểm tra lại URL, key và model, sau đó bấm nút Áp dụng. Khi hiện thông báo thành công, hãy đóng rồi mở lại Codex nếu ứng dụng chưa nhận cấu hình.

B4 · Bắt buộc

Cập nhật config.toml

Tìm block [model_providers.9router] đang có trong file rồi bổ sung các dòng bên dưới. Thay sk-your-key bằng API key của bạn; giữ nguyên các phần cấu hình khác.

[model_providers.9router]
name = "9Router"
base_url = "https://aixingialaire.shop/cdx/v1"
wire_api = "responses"
experimental_bearer_token = "sk-your-key"
requires_openai_auth = false
  • Windows: C:\Users\Tên máy của bạn\.codex\config.toml
  • Ubuntu: ~/.codex/config.toml
  • Model và Subagent Model được chọn ở bước B2 trong 9Router.
  • Không xóa thư mục .codex hoặc thư mục sessions; chỉ cập nhật block cấu hình.

Sau khi lưu file, khởi động lại Codex Desktop. Nếu vẫn thấy endpoint cũ, mở lại trang CLI Tools của 9Router và bấm Áp dụng một lần nữa.

Custom Codex · Tải ứng dụng

Dùng app Custom Codex

Nếu không muốn cấu hình thủ công, tải bản phù hợp với máy của bạn. Bản Windows là file ZIP chứa app chạy bằng .exe; bản Linux là AppImage.

⬇ Windows · Custom Codex (.zip)⬇ Linux / Ubuntu · AppImage
  • Windows: giải nén ZIP rồi mở file .exe bên trong.
  • Linux / Ubuntu: cấp quyền chạy cho AppImage rồi mở ứng dụng.
  • Ứng dụng dùng riêng cấu hình của nó, không xóa thư mục sessions Codex cũ.
