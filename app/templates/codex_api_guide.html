PHP TOOL · Codex API

Dùng Codex theo cách bạn muốn

Chọn một phương thức bên dưới để xem hướng dẫn chi tiết. Bạn có thể đổi phương thức bất cứ lúc nào bằng thanh bên trái.

Codex · 9router

Kết nối Codex Desktop qua 9router

Làm lần lượt bốn bước. Tên nút và đường dẫn tiếng Anh giữ nguyên như trong 9Router.

B1

Mở trang Codex trong 9Router

Mở CLI Tools → Codex theo liên kết này:

{{ router_url }}
B2

Nhập thông tin

Chọn Custom URL, nhập gateway, chọn Custom API key và chọn model Codex cần chạy.

Custom URL
{{ gateway_url }}
B3

Ấn Lưu / Áp dụng

Kiểm tra URL, key và model rồi bấm Áp dụng. Khởi động lại Codex Desktop nếu ứng dụng chưa nhận cấu hình.

B4

Cập nhật file config.toml

Tìm block [model_providers.9router] và bổ sung đúng các dòng sau. Chỉ thay sk-your-key bằng key của bạn.

[model_providers.9router]
name = "9Router"
base_url = "https://aixingialaire.shop/cdx/v1"
wire_api = "responses"
experimental_bearer_token = "sk-your-key"
requires_openai_auth = false
  • Windows: C:\Users\Tên máy của bạn\.codex\config.toml
  • Ubuntu: ~/.codex/config.toml
  • Không xóa thư mục .codex hoặc thư mục sessions Codex cũ.
Codex · cockpit tools

Nhập key vào cockpit tools

Cockpit Tools có thể nhập tài khoản Codex từ file JSON mà bot gửi cho bạn, sau đó chạy key ngay trong tài khoản đã nhập.

B1

Mở Cockpit và chọn Codex

Mở Cockpit Tools, tại thanh bên trái ấn Codex. Sau đó ấn nút dấu + ở góc phải để thêm tài khoản.

B2

Nhập từ tệp cục bộ

Trong cửa sổ Thêm tài khoản Codex, chọn Nhập, sau đó chọn Nhập từ tệp cục bộ. Chọn file .json mà bot đã gửi cho bạn.

B3

Chạy key

Sau khi tài khoản xuất hiện trong danh sách, chọn đúng tài khoản rồi ấn nút Chạy key (biểu tượng play). Kiểm tra trạng thái Hiện tại và hạn mức trước khi mở Codex.

Không chỉnh sửa hoặc chia sẻ file JSON đầy đủ; file có thông tin phiên đăng nhập của bạn.

Codex · app custom codex

Dùng app custom codex

Nếu không muốn cấu hình thủ công, tải app đúng hệ điều hành. Ứng dụng chạy độc lập và không xóa dữ liệu Codex Desktop cũ.

B1

Tải và mở ứng dụng

⬇ Windows · Custom Codex (.zip)⬇ Linux / Ubuntu · AppImage
  • Windows: giải nén ZIP rồi mở file .exe.
  • Linux / Ubuntu: cấp quyền chạy cho AppImage rồi mở ứng dụng.
B2

Nhập key

Mở Settings / Cài đặt, dán key sk-... vào ô API key rồi nhập URL gateway nếu app yêu cầu.

Gateway URL
{{ gateway_url }}
B3

Chọn model và lưu

Chọn model Codex được phép, chọn effort phù hợp, rồi ấn Lưu / Apply. Các cuộc trò chuyện Codex cũ trên máy vẫn được giữ nguyên.

    {% for model in models %}
  • {{ model }}
    • {% endfor %}
