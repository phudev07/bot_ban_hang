CÁCH 01

Nếu đã có 9Router

9Router sẽ quản lý cấu hình Codex. Cách này yêu cầu 9Router đang chạy trên máy.

9ROUTER / CLI TOOLS

Điền đúng 5 trường

Không dùng endpoint localhost làm Custom URL. Endpoint API cần là địa chỉ gateway HTTPS bên dưới.

Mở 9Router trên máy
  1. Mở trang OpenAI Codex CLI / AppTruy cập http://localhost:20128/dashboard/cli-tools/codex.
  2. Select Endpoint → Custom URLNhập {{ gateway_url }}.
  3. Khóa API → CustomDán key sk-... vừa nhận sau khi kích hoạt CDK.
  4. Chọn Model và Subagent ModelDùng cùng một model: cx/gpt-5.6-sol hoặc cx/gpt-5.5.
  5. Bấm Áp dụngĐóng và mở lại Codex App/CLI nếu phiên đang chạy chưa nhận cấu hình mới.

CÁCH 02

Tự sửa hai file cấu hình

Cách dành cho người quen thao tác file. Mẫu đã dùng cấu trúc Codex hiện tại và cấu hình cả model mặc định cho subagent.

MANUAL CONFIG

Thư mục .codex ở đâu?

Mở File Explorer, dán đường dẫn %USERPROFILE%\.codex vào thanh địa chỉ rồi Enter.

Ví dụ:C:\Users\Tên máy\.codex

Nếu chưa có thư mục .codex, hãy tự tạo thư mục mới với đúng tên đó.

{% for model in models %}{% endfor %}

config.toml
# VietShare Codex Setup
model = "cx/gpt-5.6-sol"
model_provider = "vietshare"
cli_auth_credentials_store = "file"

[model_providers.vietshare]
name = "VietShare Gateway"
base_url = "{{ gateway_url }}"
wire_api = "responses"
requires_openai_auth = true

[agents]
default_subagent_model = "cx/gpt-5.6-sol"
File 2 · auth.jsonC:\Users\Tên máy\.codex\auth.json
auth.json · chỉ thay sk-your-key
{
  "auth_mode": "apikey",
  "OPENAI_API_KEY": "sk-your-key"
}
Quan trọng:Đóng Codex trước khi lưu. Trong auth.json, chỉ thay sk-your-key bằng key thật; giữ nguyên dấu ngoặc kép và dấu phẩy.
CLAUDE CODE

Tự cấu hình Claude Code

Nếu không dùng công cụ portable, bạn chỉ cần tạo hoặc sửa một file settings.json trong thư mục .claude.

MANUAL CONFIG

Thư mục .claude ở đâu?

Mở File Explorer, dán %USERPROFILE%\.claude vào thanh địa chỉ rồi Enter.

Ví dụ:C:\Users\Tên máy\.claude\settings.json

Claude Code tự nối đường dẫn /v1/messages, vì vậy Base URL phải để đúng phần domain, không thêm /v1.

{% for model in claude_models %}{% endfor %}
File · settings.jsonC:\Users\Tên máy\.claude\settings.json
settings.json · chỉ thay sk-your-key
{
  "model": "claude-opus-5",
  "env": {
    "ANTHROPIC_BASE_URL": "{{ claude_gateway_url }}",
    "ANTHROPIC_AUTH_TOKEN": "sk-your-key",
    "ANTHROPIC_MODEL": "claude-opus-5",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-5",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-5",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-haiku-4-5",
    "ANTHROPIC_DEFAULT_FABLE_MODEL": "claude-fable-5"
  }
}
Quan trọng:Chỉ thay sk-your-key bằng key thật. Lưu file, thoát hoàn toàn Claude Code rồi mở lại để nhận cấu hình mới.
KIỂM TRA

Sau khi kết nối

Mở lại Codex App/CLI hoặc Claude Code, tạo một cuộc trò chuyện mới và kiểm tra model đang chọn. Nếu có lỗi, đối chiếu nhanh theo mã bên dưới.

401Key sai hoặc đã bị thu hồi

Kiểm tra key có bắt đầu bằng sk-, không thừa dấu cách và vẫn còn hiệu lực.

403Model không thuộc gói key

Chọn model khác trong danh sách Codex/Claude hoặc kiểm tra quyền của key.

429Hết quota hoặc đang giới hạn

Kiểm tra quota của key. Nếu vừa gọi liên tục, chờ ngắn rồi thử lại.
